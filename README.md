# 智慧品質檢驗早報與趨勢預警系統 (Quality Intelligence & Early Warning System)

符合工業級品管規範 F01 ~ F16 全功能之智慧品質檢驗、SPC 趨勢分析、每日早報與預警閉環管理平台。

## 功能特性 (F01 ~ F16)
- **F01 檢測資料匯入與登錄**：支援 Excel 批次匯入預覽、Word 萃取、ERP 轉入與人工登錄，顯示成功/失敗/重複筆數。
- **F02 統一資料欄位**：保存檢測時間、批號、產品、厚度、取樣位置 (LM/邊部)、測試項目、方向、數值、單位、方法與目的。
- **F03 資料品質檢查門禁**：嚴格區分「未測 (Not Tested)」、「缺資料 (Missing)」與「數值 0」，單位自動換算把關。
- **F04 每日品質早報**：支援週一納入週五至週日跨週末彙整，每筆超規與提醒均可穿透回查來源數據。
- **F05 多時間尺度趨勢**：日、週、月、季及 8 年全量歷史切換，呈現原始散點、均值、MA 移動平均與規格限。
- **F06 分組與位置比較**：LM 中心線與邊部 (Edge DS/WS) 獨立分離追蹤與同圖重疊比較，防混算保護。
- **F07 規格與判讀設定**：版本控制生效日期；斜對角差/翹曲下降為「改善 (綠色)」，強度下降為「劣化注意 (紅色)」。
- **F08 超規與緩變預警**：單點超規 (OOC)、接近界限、連續 6 點單向下降 (Run/Trend)、基準偏移 (Shift)。
- **F09 製程變更標註 (4M)**：標註 4M 異動事件線，比較前後物性均值與 Cpk，嚴格標註待確認因果。
- **F10 預警處理追蹤 (CAPA)**：指派負責人、排查假說、複測紀錄、結案與去重。
- **F11 跨 8 年歷史檢索**：標註歷史機台升級與標準改版之「不可直接比對」警語。
- **F12 異常案例資料庫**：雙色標籤嚴格區分「推測原因 (Hypothesis)」與「已驗證原因 (Verified Cause)」。
- **F13 AI 案例檢索與摘要**：自然語言技術問答，嚴格標註來源案例與批號，無依據明確告知。
- **F14 AI 早報草稿產生**：自動彙整當期檢測數據與 4M 異動生成早報，主管線上審核發布。
- **F15 異常風險預測**：前瞻評估超規機率，嚴格時間先後切分訓練集與驗證集。
- **F16 成效統計看板**：試辦前後量化對比（早報工時縮減 86.7%、資料瑕疵下降 92.8%、提前 3.6 批預警）。

## GitHub Pages 部署指南

本專案已配置完整 GitHub Actions 自動建置與部署流程。

### 關鍵設定步驟 (解決畫面空白)：
1. 進入 GitHub 儲存庫：`https://github.com/ray2307ray-source/1028`
2. 點選上方 **Settings** > 左側 **Pages**。
3. 在 **Build and deployment** > **Source** 下拉選單中：
   - 請將原本的 **`Deploy from a branch`** 改選為 **`GitHub Actions`**。
4. 推送程式碼後，GitHub Actions 將會自動執行 `.github/workflows/deploy.yml`，完成 Vite 編譯打包並發布至：
   👉 **`https://ray2307ray-source.github.io/1028/`**
